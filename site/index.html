Quick start

  1. Download and run SSTD-Setup.exe.
  2. Install and start Ollama separately.
  3. Pull a model, for example:
    ollama pull qwen2.5:7b-instruct
  4. Open SSTD, connect to http://localhost:11434, and select a model.
  5. Review Settings → Automation before enabling desktop control.

Safety boundary

SSTD is not a terminal. It uses a closed, validated action registry and an independent security engine. It blocks terminals/shells, administration/system configuration tools, credential managers and password contexts. It does not overwrite existing files. External commits and model downloads require explicit approval. Desktop control starts disabled.
